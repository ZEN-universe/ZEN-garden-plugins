############
Overview
############

**Welcome to the ZEN-garden plugin template**

This package contains plugins, extensions, and add-ons for the ZEN-garden
optimization model. It also serves as a template for users to implement their
own plugins.

Please refer to the `ZEN-garden documentation <https://zen-garden.readthedocs.io/en/latest/files/plugins/overview.html>`_
for an introduction to the plugin system and a tutorial on how to implement your own plugin.

The following plugins are available:

- :doc:`../available_plugins/template_plugin/template_plugin`
- :doc:`../available_plugins/plugin_template_add_new_constraint/plugin_template_add_new_constraint`
